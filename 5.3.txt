Released: December 27, 2020


Particle and Vector Update
+ Added the Vector value type (a force with direction and magnitude represented by 3 coordinates)
+ Added new Set Variable actions for vector manipulation
+ Particles now support custom motion, cluster size, color and more
+ Added new Set Variable actions for particle manipulation
+ Added new particle types: Block, Item, Instant/Ambient Effect

New Actions/Values
+ Player Fish Event
+ Player Action: Set Rotation, Set Instant Respawn, Display Gateway Beam, Set to Spectator Mode, Spectate Target, Set Velocity, Face Location, Get Target Entity, Display Particle Cuboid
+ Entity Action: Set Invisible, Set Pose, Jump, Set Celebrating, Set Item Stack, Set Item Persistent, Set Riptiding, Set Fishing Wait Time, Set Velocity
+ Game Action: Set Campfire Item, Repeat: Repeat on Path
+ Set Variable: Raycast to Block/Entity, Set Map Texture, Get Head Owner, Remove Enchantment, Get/Set Item Potion Effects, Get/Set Lodestone Compass Location, Set to Bitwise Operation
+ Game Value: Inventory Event Click Type, Event Fish Type, Velocity
