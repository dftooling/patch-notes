Friends
+ Added a Friend system!
+ You can add friends with /friend add <player>
+ Invite your friends to join you with /friend joinme <friend>
+ Check what your friends are doing with /friend list (or /f list for short)
+ Get notified when a friend joins DiamondFire
+ Added 3 new related preferences (Hover)
» Expanded the Receive Private Messages preference to 3 options: Everyone, Friends, and No one

Minecraft 1.21.8

+ You can now use all the new mobs, entities, sounds, particles, and attributes all the way from the Bundles of Bravery drop to the Chase the Skies drop!
+ Added 24 new events, actions, and values for the version's content (Hover)
- Removed 4 Actions (hover)
+ Added 6 new /item sub-commands aswell as a particle command (Hover)
+ Added a new Happy Ghast pet allowing up to 3 other passengers, costing 50 tokens

Code Block Copying
+ Individual code blocks and their contents can now be copied with middle-click!
→ Middle-click on a sign copies the code block (not including chest contents)
→ Shift + Middle-click on a sign copies the code block (including chest contents)
→ Middle-click on a bracket copies the code block and its contents (not including chest contents)
→ Shift + Middle-click on a bracket copies the code block and its contents (including chest contents)
→ The result item can be placed in the code space like a normal code block
