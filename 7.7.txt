Private Node Changes
+ Private Nodes now have 100MB of saved variable storage (+566% from 15MB!)

String Changes

» Player Event: Player Projectile Hit Event now supports the Victim target
≈ Fixed Set Variable: Wrap Number failing if the lower and upper bounds are equal
